# My First Weather App 🌦️

This is a beginner-friendly weather application that allows users to view current weather information for any city using a simple interface. The app fetches data from a weather API and displays it dynamically.

## Features

- Search for weather by city
- Displays temperature, humidity, and conditions
- Responsive and clean UI

## Tech Stack

- HTML
- CSS
- JavaScript
- Weather API (e.g., OpenWeatherMap)
